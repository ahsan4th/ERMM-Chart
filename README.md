# ERMM-Chart designer

Interactive design, monitoring and diagnosis of the **EWMA robust Max-M chart
(ERMM-Chart)**, a control chart that monitors the mean vector and the
covariance matrix of daily multivariate quality characteristics with a single
statistic. The in-control parameters are estimated with the reweighted
Fast-MCD estimator, and the control limit is calibrated by Monte Carlo
simulation for the size of the reference period that is actually available.

The app links three activities that are usually handled separately:

1. **Product design** – specification limits of the product are entered and
   translated into the mean and variance shifts that would produce a chosen
   nonconforming fraction (critical shifts).
2. **Chart design** – the control limit is calibrated for the plant's
   reference size, and weighting constants are compared on the critical shifts.
3. **Manufacturing** – the chart is run on new production days, every signal
   is decomposed into its location and successive-difference components and
   characteristics, and mapped to the process unit to check first.

It accompanies the article *Interactive design of a robust EWMA Max-M control
chart linking product specifications to finish-mill operation in cement
manufacturing* (Radjid, Ahsan, Wibawati and Lee).

## Run it

```bash
git clone https://github.com/ahsan4th/ERMM-Chart.git
cd ERMM-Chart
pip install -r requirements.txt
streamlit run app.py
```

The app opens in the browser with a synthetic demo data set. To host it,
deploy the repository on [Streamlit Community Cloud](https://share.streamlit.io)
with `app.py` as the main file.

## Workflow (tabs)

| Tab | What the engineer does |
|---|---|
| ① Product & process | load daily records, enter specification limits, link each characteristic to a process unit and a first check |
| ② Reference period | compare classical and Fast-MCD estimates, inspect the days excluded from the reference |
| ③ Chart design | look up or calibrate the limit for the actual N and p, derive critical shifts from the specifications, compare λ by simulated ARL |
| ④ Monitoring | run the chart, see signals and production stops, export the table |
| ⑤ Diagnosis & action | split a signal into |U| and |V|, rank characteristics, map them to the action plan, compare product properties, download a report |

## Data format

A CSV file with one row per production day: a date column, the quality
characteristics (numeric) and, optionally, product properties (e.g. setting
time, compressive strength). The first N rows form the reference (Phase I)
period; N is chosen in the sidebar or taken from a column `Phase` with values
`I` and `II`.

`data/opc_synthetic.csv` is **synthetic**. The plant records used in the
article are confidential; the demo data are generated by
`data/make_synthetic_data.py` from the published summary statistics of the
case study (Tables 5, 6, 7, 15 and 16 of the article) and must not be read as
plant data. `data/specifications_demo.csv` contains the LOI limit of SNI
2049:2015 (Type I) and illustrative internal limits for the other
characteristics, which should be replaced by the plant's own values.

## Method

For day t with characteristics **x**_t, the location and successive-difference
quadratic forms

Q_U,t = (**x**_t − **μ̂**)ᵀ Σ̂⁻¹ (**x**_t − **μ̂**),  Q_V,t = ½ (**x**_t − **x**_t−1)ᵀ Σ̂⁻¹ (**x**_t − **x**_t−1)

are transformed to the normal scale, U_t = Φ⁻¹{H_p(Q_U,t)}, V_t = Φ⁻¹{H_p(Q_V,t)},
combined as M_t = max(|U_t|, |V_t|) and smoothed,
ERMM_t = λ M_t + (1 − λ) ERMM_t−1 with ERMM_0 = 2/√π. The chart signals when
ERMM_t > UCL = μ_M + L σ_M √(λ/(2 − λ)), with L calibrated so that the in-control
ARL equals the target when μ̂ and Σ̂ come from a reference sample of size N.

## Validation

* `ermm/estimators.py` follows `robustbase::covMcd` (α = 0.75, reweighting at
  χ²_p;0.975, consistency and small-sample corrections). Centres and covariance
  matrices agree with robustbase 0.99-2 to within 1e-14 and the excluded
  observations are identical (`tests/test_estimators.py`).
* Control limits calibrated with 10,000 replications reproduce the limits of
  the article (Table 10) within Monte Carlo error
  (`notebooks/validation.ipynb`, executed).
* `pytest tests` runs the unit tests (estimator, invariance, EWMA recursion,
  design rule, calibration).
